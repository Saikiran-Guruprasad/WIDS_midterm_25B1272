# WIDS_midterm_25B1272

This project, up till now, has been very interesting and extremely fun. Having been a beginner to the world of Data science, the integration of basic principles in data analytics is insightful and entertaining.

In the 1st week, I was asked to learn python till a basic level (to a level of simply understanding the language, not going into programming techniques). After gaining a strong hold on basic python, I was introduced to the basic of what machine learning is.

In the 2nd week, I was introduced to the concept of pandas for ML. Further, I was taught about various Data Science methods/algorithms like linear regression, cost function, gradient descent, etc. (theoretically) and was taught the different types of ML. Also, I was introduced to the concept of neural networks, and how such networks function.

In the 3rd week, I was made to do a hands on, interactive assignment on google colab, to simulate the concept of linear regression. I was asked to fill in the blanks, and write various code snippets, as part of the assignment. Here, I learnt about what are all the steps needed to deal with linear regression. Further, I was exposed to building and training a neural network. I was also shown why neural networks are superior and needed as compared to using a simple linear regression model.

In the 4th week, I was taught about evaluation metrics in ML. This taught me the various evaluation metrics used and its importance in the grand view of ML. As part of the assignment, implementation of CNN (Convolutional Neural Network) was introduced. Here, using information from the MNIST data set, we were asked to train the ANN first with the training data and then to find out the accuracy. Next, we were instructed to train the CNN with the same data, and then obtain the resultant accuracy figures. Similarly, we were asked to fill in the blanks and write out code snippets.

This project, till now, has been extremely interactive and interesting. My assigned mentor too, has been excellent and caring throughout these 4 weeks. I look forward to an exciting week ahead in this project.
